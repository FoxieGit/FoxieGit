## 🧠 About Foxie

**Foxie** is a Brazilian software company focused on building modern enterprise systems, ERP platforms, automation tools, and AI-powered products.

Our ecosystem is designed to connect business operations, industrial intelligence, creative workflows, and scalable digital infrastructure.

We build software for companies that need more than simple management tools — they need systems that understand operations, react to events, reduce dependency on manual processes, and create real strategic value.

---

## 🚀 What We Build

### 🏢 Foxie ERP

A complete enterprise resource planning ecosystem designed for real business operations.

Core areas:

- Sales and order management
- Financial control
- Receivables and payables
- Production workflows
- PCP / production planning
- Inventory and stock movement
- Billing and invoicing
- Operational approvals
- Audit trails
- Business dashboards
- Multi-company structure
- Secure access control

---

### 🎨 Pattern AI Engine

An AI-powered creative engine for textile and pattern design.

Built to transform a proprietary archive of 40,000+ original textile patterns into a structured creative intelligence system.

Core goals:

- AI-generated textile patterns
- Category-based generation
- Style and palette control
- Seamless / rapport validation
- Originality checking
- Human curation workflow
- Layered export pipeline
- PSD / PSB / editable layer package support
- Dataset management
- LoRA training pipeline

---

### ⚙️ Automation Systems

Internal automation tools designed to reduce repetitive work, improve operational visibility, and increase decision speed.

Focus areas:

- Workflow automation
- Approval flows
- Event-driven alerts
- Operational logs
- Internal dashboards
- Intelligent data processing
